# Ghi Điểm

Ứng dụng ghi điểm cho bóng đá, cầu lông, bóng chuyền, bóng bàn và tennis. Mỗi môn tính điểm theo luật riêng,
có đồng hồ bấm giờ từ lúc trận bắt đầu, và mỗi điểm / bàn thắng được lưu kèm thời gian.

## Build

Nhấn **Ctrl+Shift+B** trong VS Code, rồi chép file APK trong `build\apk\` sang điện thoại và mở để cài.

Chi tiết cho người phát triển: xem `CLAUDE.md`.
